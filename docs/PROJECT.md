# Protect ThaiHealth — ปกป้องความเป็นอิสระของ สสส.

> สถานะ ณ 5 ต.ค. 2569 · ระบบทำงานในเครื่อง (localhost:3000) ยังไม่ได้ขึ้นเซิร์ฟเวอร์จริง

ระบบลงชื่อออนไลน์ด้วยลายเซ็นนิ้ว สำหรับให้เครือข่ายองค์กรภาคประชาสังคมในไทยและต่างประเทศ
ร่วมสนับสนุนแถลงการณ์คัดค้านร่างแก้ไข พ.ร.บ. กองทุนสนับสนุนการสร้างเสริมสุขภาพ
(เริ่มจากที่ประชุมเครือข่าย NGO 100 กว่าคน แล้วส่งต่อออนไลน์)

**สาระสำคัญ**
1. ยกเลิกเงินบำรุงกองทุนร้อยละ 2 จากภาษีสุราและยาสูบ (มาตรา 11–15 ของ พ.ร.บ. ปี 2544)
   แล้วให้ได้รับ "เงินจากงบประมาณรายจ่ายประจำปี" แทน
2. แก้ "เงินอุดหนุนจากรัฐบาล" เป็น "เงินอุดหนุนจากรัฐบาลตามความจำเป็น"
3. เหตุผลที่ผู้เสนอให้ไว้: รักษาวินัยการเงินการคลังตามมาตรา 26 ของ พ.ร.บ. วินัยการเงินการคลังของรัฐ พ.ศ. 2561

**คำถามรับฟังความเห็น 4 ข้อของรัฐสภา**
1. เห็นด้วยหรือไม่กับการแก้ไขเงินและทรัพย์สินของกองทุน (ยกเลิกเงินบำรุง 2% → งบประมาณรายจ่ายประจำปี, เงินอุดหนุน "ตามความจำเป็น")
2. เห็นด้วยหรือไม่กับการยกเลิกมาตรา 11–15
3. พ.ร.บ. ปี 2544 มีปัญหาหรือผลกระทบอย่างไร และร่างนี้แก้ได้หรือไม่
4. ข้อคิดเห็นอื่น ๆ

ตอนที่ตรวจ (5 ต.ค. 2569) มีผู้แสดงความเห็น 11,609 คน ตัวเลขบนหน้าน่าจะหมายถึงไม่เห็นด้วยราว 96.78%

### แดชบอร์ดแอดมิน (`/dashboard/campaigns`)
- สร้าง/แก้ไขแคมเปญ (ข้อความ 2 ภาษา), เปิด-ปิดรับลงชื่อ, ตั้งเวลาปิดอัตโนมัติ
- สถิติ: รายชื่อทั้งหมด / ประเทศ / องค์กรร่วมลงนาม (นับองค์กรไม่ซ้ำ เฉพาะคนที่ลงในนามองค์กร) / ในนามส่วนตัว / วันนี้ / มีความคิดเห็น + กราฟแยกประเทศ
- ตารางรายชื่อพร้อมภาพลายเซ็น ค้นหาได้ ขยายอ่านความคิดเห็นได้ ลบรายชื่อได้ (กดยืนยัน 2 จังหวะ)
- ส่งออก Excel (CSV ภาษาไทยไม่เพี้ยน)
- หน้าพิมพ์ **ครบทุกฟิลด์** (ลงนามในนาม, ชื่อ-นามสกุล, องค์กร/ตำแหน่ง, อีเมล, ประเทศ, วันที่, ลายเซ็น, ความคิดเห็น) A4 แนวนอน
  → ปุ่ม "พิมพ์ / บันทึก PDF" + "ส่งออก Excel (CSV)" อยู่ในหน้าเดียวกัน

### ความปลอดภัย / ความเป็นส่วนตัว
- ภาพลายเซ็น อีเมล นามสกุล และองค์กร เปิดดูได้เฉพาะแอดมิน · ความคิดเห็นขึ้นหน้าสาธารณะเฉพาะคนที่เลือกแสดงชื่อ

## 4. ก่อนใช้งานจริง

1. **ตรวจข้อความแถลงการณ์** (ไทย + อังกฤษ) — เป็นร่างที่เขียนจากข้อเท็จจริงในโพสต์และหน้ารัฐสภาเท่านั้น
   - ข้อ 2 "เป็นต้นแบบที่หลายประเทศนำไปศึกษา" ยังไม่ได้ตรวจแหล่งอ้างอิง → ระบุแหล่งหรือตัดออก
   - ข้อเรียกร้องข้อ 3 (อีก 3 กองทุน) อ้างจากโพสต์ ยังไม่ได้เปิดอ่านร่างของแต่ละกองทุน
   - แก้ได้ที่ แดชบอร์ด → แคมเปญลงชื่อ → แก้ไขแคมเปญ
2. **ขึ้นเซิร์ฟเวอร์จริงก่อนวันประชุม** — ขั้นตอนครบใน `docs/DEPLOY.md` — ตอนนี้ QR ชี้ `localhost` มือถือเปิดไม่ได้
   - โดเมนควรสื่อชื่อใหม่ เช่น `protectthaihealth.org` หรือ `protect.sdnthailand.com` (ไม่ให้คนเข้าใจผิดว่าเป็นเว็บรัฐสภา)
   - รัน SQL ใน `prisma/production-sql/` ตามลำดับ: `init` → `campaign-signatures` → `signature-comment` → `signature-signing-as` → `campaign-hero` → `campaign-official-closes`
   - **ข้อมูลแคมเปญ (ข้อความ/ปก/วันปิด) ไม่อยู่ใน SQL** — รัน `node scripts/seed-thaihealth-campaign.mjs` บนเซิร์ฟเวอร์ หรือสร้างในแดชบอร์ด
   - ตั้ง `.env` บนเซิร์ฟเวอร์ (NEXTAUTH_SECRET ใหม่, NEXTAUTH_URL เป็นโดเมนจริง) + เพิ่ม redirect URI ของ Google
3. ทดสอบบนมือถือจริงหลายรุ่น (iPhone / Android) ทั้งเซ็นชื่อและส่งฟอร์มผ่านเน็ตมือถือ

## 5. ผลทดสอบความสะดวก (5 ต.ค. 2569, production build)
| รายการ | มือถือ (390px) | คอม (1400px) |
|---|---|---|
| เวลาตอบสนองเซิร์ฟเวอร์ | 5–30 ms | เดียวกัน |
| ขนาด JS+CSS (gzip) | ≈ 217 KB | เดียวกัน |
| ใช้งานหน้าได้ (DOMContentLoaded) | – | 88 ms |
| ไปถึงฟอร์ม | ปุ่ม "ร่วมลงชื่อ" ใต้ตัวนับ + ปุ่มลอยด้านล่างจอ (เดิมต้องเลื่อน 3 หน้าจอ) | ปุ่ม "ร่วมลงชื่อ" ข้างตัวนับ |
| ช่องกรอกตัวอักษร ≥ 16px (iPhone ไม่ซูมเอง) | ✔ | ✔ |
| เลื่อนแนวนอนเกินจอ | ไม่มี | ไม่มี |
| ปุ่ม Tab/ถัดไป เรียงช่องถูกลำดับ | ✔ | ✔ |
| เลือกประเทศด้วยการพิมพ์ | – | ✔ (พิมพ์ "Japan" ได้ทันที) |
